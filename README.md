# Xadrez 2 — Definitive Edition

Versão melhorada em HTML, CSS e JavaScript puro.

## Recursos
- Xadrez clássico com roque, en passant, promoção e xeque-mate.
- Modo Especial 16×8 com Mago, Arqueiro, Dragão e Guardião.
- Casas especiais: Portal, Poço de Energia e Armadilha.
- Eventos climáticos opcionais.
- Cronômetros configuráveis.
- Desfazer movimento.
- Histórico em notação algébrica.
- Exportação PGN.
- Salvamento e continuação via LocalStorage.
- Tabuleiro virável.
- Temas Madeira, Meia-noite e Mármore.
- Interface responsiva para desktop e celular.

Abra `index.html` em qualquer navegador moderno.
